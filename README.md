# 🪙 CoinPulse

Premium Telegram Mini App Clicker built with React, TypeScript and Tailwind CSS.

---

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Zustand
- Telegram Web Apps API

---

## ✨ Features

- Animated clicker
- Telegram Mini App integration
- XP & level system
- Daily rewards
- Premium UI/UX
- Smooth animations

---

## 📦 Installation

```bash
npm install
npm run dev
```
